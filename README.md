# Music Grabber

Музичний застосунок для Windows: пошук, прослуховування й завантаження музики
з тегами та обкладинками. Побудований на Electron, качає через
[yt-dlp](https://github.com/yt-dlp/yt-dlp), обробляє через
[FFmpeg](https://ffmpeg.org/).

> *A desktop music app (Ukrainian UI): search across YouTube Music, SoundCloud,
> iTunes and MusicBrainz, stream without downloading, grab tracks with proper
> tags and embedded artwork, manage a local library and playlists.*

---

## Що вміє

**Пошук і рекомендації**
- Пошук одночасно по YouTube Music, SoundCloud, iTunes і MusicBrainz —
  окремими вкладками: треки, альбоми, виконавці.
- Головна сторінка з живими добірками YouTube Music (чарти, локальні хіти).
- Радіо за будь-яким треком — власні рекомендації YouTube Music.
- Історія прослуханого й улюблене.

**Прослуховування**
- Програвання просто з результатів пошуку, без завантаження.
- Черга відтворення видима: видно, що гратиме далі, треки переставляються й
  прибираються, будь-що можна кинути «наступним».
- Перемішування, повтор, текст пісні.
- Гарячі клавіші: `Пробіл` — пауза, `←`/`→` — перемотка, `N`/`P` — сусідні
  треки, `Q` — черга, `L` — текст, `F` — в улюблене.
- Медіаклавіші клавіатури й навушників працюють і зі згорнутим вікном, а
  системна панель Windows показує обкладинку й назву.

**Завантаження**
- Правильні імена файлів: `Виконавець - Назва`.
- Вшита обкладинка, обрізана в квадрат, і заповнені теги.
- Цілі альбоми та добірки — одним завданням, у власну теку.
- Тимчасові збої (403, 429, тайм-аути) повторюються автоматично.

**Своя музика**
- Сховище читає теги напряму з файлів, без власної бази.
- Редактор тегів із пакетним перейменуванням.
- Плейлисти.
- Статус у Discord: що саме зараз грає.

## Звідки береться музика — і звідки не береться

| Джерело | Пошук | Звук |
|---|---|---|
| YouTube Music | так | так |
| YouTube | за посиланням | так |
| SoundCloud | так | так |
| iTunes | каталог альбомів | ні |
| MusicBrainz | каталог виконавців | ні |
| Spotify, Apple Music | за посиланням | **ні — DRM** |
| Bandcamp | ні — захист від автоматів | за посиланням |

**Spotify та Apple Music** віддають захищений потік — завантажити звідти
неможливо жодним інструментом. Посилання з них усе одно приймаються: з них
беруться назва й виконавець, а сам звук шукається в YouTube Music. Застосунок
про цю підміну повідомляє прямо.

**FLAC свідомо відсутній.** Джерела віддають лише стиснутий звук, тому FLAC
означав би файл утричі більший без жодного виграшу в якості. Доступні:
`OPUS` (~155 kb/s, найкраще з наявного), `M4A` (~130 kb/s, грає скрізь) і
`MP3 320` — єдиний варіант із перекодуванням.

## Встановлення

Готовий інсталятор несе **yt-dlp і FFmpeg у собі** — качати їх окремо не
треба. Через це він і важкий (близько 100 МБ), зате після встановлення все
працює одразу.

yt-dlp оновлюється сам, раз на добу: YouTube регулярно змінює свій бік, і
стара версія просто перестає качати. Свіжа копія лягає в профіль користувача,
тому права адміністратора не потрібні, а тека з програмою лишається як була.
Вимикається в Налаштуваннях, там же є кнопка «Перевірити оновлення».

## Запуск із вихідних кодів

Потрібен [Node.js](https://nodejs.org) 20+.

```bash
npm install --prefix app
npm run bins --prefix app
npm start --prefix app
```

`npm run bins` кладе yt-dlp та FFmpeg у теку `app/bin`. Той самий крок
виконується автоматично перед складанням, тож інсталятор ніколи не виходить
без них.

У Windows простіше — подвійний клік по `Music Grabber.bat` (він сам поставить
залежності при першому запуску).

Застосунок шукає FFmpeg і yt-dlp у такому порядку: свіжа копія в профілі
користувача, далі вшита в програму (`app/bin`), далі `PATH`, далі типові місця
встановлення. Якщо чогось бракує, він скаже про це у вікні, а пошук
працюватиме й далі.

## Тести

```bash
npm test --prefix app
```

Два набори: перевірка завантаження (аргументи yt-dlp, реальний файл, теги,
обкладинка) і наскрізна перевірка інтерфейсу — вона піднімає справжнє вікно
й керує ним через DevTools-протокол. Змінна `MG_SHOTS=<тека>` вмикає знімки
вікна: частину помилок видно тільки оком.

## Статус у Discord

У застосунок вшито ID додатка Discord, тому нічого налаштовувати не треба —
досить увімкнути галочку в Налаштуваннях. Щоб підставити свою назву, створи
власний додаток на
[discord.com/developers](https://discord.com/developers/applications) і встав
його Application ID у те саме місце. Це не таємниця: Discord показує цей ID у
кожному статусі.
